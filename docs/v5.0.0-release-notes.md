# 芒果客户端 5.0.0 意见落实记录

版本名：`5.0.0`；基础版本号：`7010`。本次修改源码并进行编译与离线回归，未生成 APK。

## 对应意见清单

| 原编号 | 修改后的行为 |
| --- | --- |
| 1 | 修复长按选择中的布局越界与失效布局访问。正文分成多个布局块时，拖动端点和判断文字方向使用块内偏移；消息重绑、图片说明布局消失或找不到对应布局时，不再复用旧布局。 |
| 2 | 自定义频道人数统一用于聊天顶部、资料页展开和折叠状态。详情尚未加载、真实人数为 0、管理员身份等情况不再覆盖本地人数；保存和恢复默认后刷新聊天顶部。按账号保存，群组、话题和频道私信沿用原来的显示。 |
| 3 | 移除自定义群组／频道名称的编辑入口和本地名称应用逻辑，显示服务器名称。旧名称设置不再生效；个人备注、频道用户名、人数和简介的本地显示功能保留。 |
| 6 | 设置页账号快速切换区域保存最后一次展开／收起状态。返回页面、重建页面和切换账号时恢复同一设备上的最新选择，初次使用默认收起。 |
| 7 | 广告白名单位于广告屏蔽页的开关下方，可添加当前账号的私聊、群组和频道。所选会话跳过关键词、屏蔽用户和赞助广告规则，长按可删除。 |
| 8 | 普通扫描二维码支持从相册选择图片；页面右上角增加“扫码登录账号”，跳转当前账号的设备登录扫码流程。拒绝相机权限后仍可选择相册；登录扫码校验登录二维码类型。 |
| 9 | 修复输入 @ 时同一用户或频道在候选列表重复出现。合并本地与服务器结果时按身份去重，用户与频道分别识别；旧请求不能清除新请求的状态。 |

退出扫码页时取消尚未提交的延迟登录任务，关闭后的识别和网络回调不再重复跳转或更新页面；Web 连续扫码保留原有行为。

## 广告白名单的范围与刷新

- 白名单按账号、会话保存，只放行所选会话；将一个私聊加入白名单不会放行该用户在其他群里的消息。
- 添加或移除白名单后，聊天重新加载消息并清理已插入及待插入的赞助广告状态，机器人顶部广告同步更新。
- 赞助广告请求返回时重新检查规则及请求身份，设置改变后失效的响应不会重新插入广告或覆盖新请求。
- 全局赞助广告开关的持久化入口统一刷新所有已登录账号，设置页操作、历史恢复和重置使用同一逻辑。

## 验证

编译命令：

```sh
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' ./gradlew \
  :TMessagesProj:compileDebugJavaWithJavac \
  :TMessagesProj:processDebugManifest --offline --console=plain
```

专项回归命令：

```sh
python3 Tools/tests/run_v50_selection_mentions_tests.py
python3 Tools/tests/run_v50_local_display_tests.py
python3 Tools/tests/run_v50_ad_whitelist_tests.py
python3 Tools/tests/run_qr_gallery_tests.py
python3 Tools/tests/run_settings_account_theme_tests.py
python3 Tools/tests/run_keyword_folder_shortcut_tests.py
python3 Tools/tests/run_mango_localization_tests.py
```

专项结果：选择与提及 38 项、频道本地显示 42 项、广告白名单与异步响应 112 项、扫码 66 项、账号区域和主题 406 条行为断言及 15 项接线检查／7 个回归变异检查、选词与分组 57 项均通过。本地化覆盖 844 个文案键、13 种语言，77,958 项资源检查及 21 项语言选择检查通过。

额外通过既有复制崩溃、文本选中、消息复制、资料页启动、头像菜单和设置存储回归。离线测试使用生产类或从生产源码提取的方法，覆盖布局失效、候选合并、白名单持久化和异步回调等行为；不连接 Telegram 或远程词库。

以上验证不包含真机触摸、相机硬件或真实账号扫码登录。设备验收应检查：长正文和图片说明的选区拖动；修改人数后返回聊天；账号区域展开／收起后重启；白名单增删及账号切换；相册取消、无二维码图片、相机权限拒绝和退出扫码页后的回调。
